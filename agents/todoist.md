# Todoist task conventions

## Task names

Format task names with the most useful context first in bold, followed by the specific item name, separated by a space and no punctuation. Do not use quotation marks. For example:

- `**Author Name** Book title`
- `**Course title** Lecture name`

## Dates and durations

When a task has a known start time, record it in Todoist's due date and time. When its duration is known, set Todoist's duration field. Apply this to any kind of task, not only scheduled sessions.

## Priorities

Use the user's Eisenhower matrix:

- Important and urgent: P1
- Important and not urgent: P2
- Not important and urgent: P3
- Not important and not urgent: P4

Treat a fixed-time event as urgent. Assess importance against the user's stated goals; do not default scheduled tasks to P4.
